# NetPrivacy Mobile — источники ссылок
# ======================================
# Формат:
#   - Строки с vless://, vmess://, trojan://, ss://  → прямые ссылки
#   - Строки с http:// / https://                   → удалённые подписки
#   - Строки начинающиеся с #                        → комментарии
#
# Примеры удалённых подписок (раскомментируй нужные):
# https://raw.githubusercontent.com/some/repo/main/nodes.txt
# https://example.com/sub?token=xxx
#
# Примеры прямых ссылок (добавляй свои):
# vless://uuid@host:443?security=reality&...#MyNode
# vmess://BASE64_PAYLOAD
# trojan://password@host:443?security=tls#TrojanNode
# ss://BASE64_AUTH@host:8388#SSNode
