# NetPrivacy Tool - Портативная версия

##Проектная выпускная работа - @TheFirSStYfOreVer

**Автоматический поиск и проверка VPN-узлов**

## Что это

NetPrivacy Tool — это программа для массовой проверки работоспособности VPN-прокси. Она загружает списки узлов из публичных источников, проверяет каждый на доступность и тестирует подключение к популярным сервисам.

## Для чего нужен

- Найти рабочие VPN-серверы для обхода блокировок
- Проверить какие узлы работают с YouTube, Telegram, Discord, Instagram
- Получить список проверенных конфигураций с метриками качества

## Системные требования

- Windows 10/11 (64-bit)
- Не требует установки (portable)
- Права администратора не нужны

## Как запустить

1. Распакуйте папку с проектом в любое место (Рабочий стол, флешка и т.д.)
2. Запустите `NetPrivacyTool.exe`
3. Нажмите **START VERIFICATION**

## Как это работает

### 1. Загрузка источников
Программа читает `data/sources.txt` — список URL с публичными VPN-конфигурациями.

### 2. Парсинг ссылок

Из каждого источника извлекаются прокси-ссылки следующих протоколов:

+-------------+----------------+-------------------------------------------------+
| Протокол    | Ссылка         | Особенности                                     |
+-------------+----------------+-------------------------------------------------+
| VLESS       | vless://...    | Современный легкий протокол от разработчиков    |
|             |                | Xray. Без шифрования заголовка (plaintext ID),  |
|             |                | работает быстрее VMess. Рекомендуется для новых |
|             |                | конфигураций.                                   |
+-------------+----------------+-------------------------------------------------+
| VMess       | vmess://...    | Классический протокол V2Ray с шифрованием       |
|             |                | заголовка. Ссылка Base64-закодирована.          |
|             |                | Устойчив к анализу трафика, но немного          |
|             |                | медленнее VLESS.                                |
+-------------+----------------+-------------------------------------------------+
| Trojan      | trojan://...   | Имитирует HTTPS-трафик (TLS). Пароль в открытом |
|             |                | виде. Хорошо маскируется под обычный веб-трафик,|
|             |                | сложно детектировать DPI.                       |
+-------------+----------------+-------------------------------------------------+
| Shadowsocks | ss://...       | Простой и быстрый socks5-прокси с шифрованием.  |
|             |                | Ссылка Base64-закодирована. Менее устойчив к    |
|             |                | блокировкам, но легкий в настройке.             |
+-------------+----------------+-------------------------------------------------+

**Как выглядят ссылки:**

- **VLESS:**       `vless://uuid@host:port?security=tls&type=ws#name`
- **VMess:**       `vmess://eyJhZGQiOiJob3N0IiwicG9ydCI6IjQ0MyIs...` (Base64 JSON)
- **Trojan:**      `trojan://password@host:port?sni=domain.com#name`
- **Shadowsocks:** `ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ=@host:port#name`

### 3. Проверка узлов
Каждый узел проверяется на:
- **Базовое соединение** — ответ от сервера
- **Доступ к ресурсам** — тест 4 сайтов:
  - **YT** — youtube.com
  - **TG** — t.me (Telegram)
  - **DC** — discord.com
  - **IG** — instagram.com

### 4. Ранжирование
Результаты сортируются:
- `HIGH RELIABILITY`---(4/4) — все сайты доступны
- `GOOD`---------------(3/4) — почти все работают
- `OK`-----------------(2/4) — половина
- `WEAK`---------------(1/4) — слабый
- `DEAD`---------------(0/4) — не работает

### 5. Сохранение
Рабочие конфиги сохраняются в `data/verified_nodes.txt` с метками доступности
или их можно скопировать в .

### Главное окно

+-----------------+-----------------------------------------------------------+
| Элемент         | Описание                                                  |
+-----------------+-----------------------------------------------------------+
| Concurrency     | Количество одновременных проверок (рекомендуется 10-200). |
+-----------------+-----------------------------------------------------------+
| START           | Запуск процесса проверки.                                 |
+-----------------+-----------------------------------------------------------+
| STOP            | Полная остановка: завершение всех активных процессов и    |
|                 | принудительная очистка временных (temp) файлов.           |
+-----------------+-----------------------------------------------------------+

### Панели

- **SYSTEM LOGS** — ход проверки в реальном времени
- **VERIFICATION RESULTS** — таблица результатов топ-15 узлов
- **CURRENT NODE** — информация о проверяемом узле
- **BEST CONFIG** — лучшая найденная конфигурация

### Горячие клавишы

- **START** — начать проверку
- **STOP** — остановка с очисткой временных файлов

## Безопасность

⚠️ **Важно**:
- Антивирус может ругаться на `core/bin/xray.exe` (это ложное срабатывание)

## Устранение неполадок

### "sources.txt not found"
Проверьте что папка `data/` находится рядом с `NetPrivacyTool.exe`

### "xray.exe not found"
Проверьте что папка `core/bin/` с `xray.exe` находится рядом с .exe, а также в ней есть "xray.exe" а если его там нет
его можно скачать отсюда: https://github.com/XTLS/Xray-core/releases/download/v26.3.27/Xray-windows-64.zip и скопируйте все файлы из архива в папку `core/bin/`.

### Нет результатов
- Проверьте интернет-соединение
- Увеличьте таймаут в исходном коде (если запускаете из Python)
- Источники могут быть недоступны — проверьте `data/sources.txt`

### Антивирус блокирует
Если ваш антивирус блокирует `xray.exe` Добавьте папку с инструментом в исключения. `xray.exe` — легитимный инструмент для прокси, но некоторые антивирусы могут помечать его как троян из-за сетевой активности но это ложное срабатывание так как xray является ядром почти любого VPN - клиента а также расположен на GitHub что даёт гарантию его безопасности.
